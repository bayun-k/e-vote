Hubungkan Database dengan Google Spreadsheet

Anda dapat menghubungkan web ini langsung ke Google Spreadsheet milik sekolah Anda untuk menyimpan hasil voting dan membaca data calon secara terpusat!

Langkah-Langkah Setup Google Sheet:

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Buka menu Ekstensi (Extensions) > Apps Script.
  3. Hapus semua isi kode default, lalu tempelkan (paste) Kode Apps Script di bawah ini:
// KODE GOOGLE APPS SCRIPT UNTUK E-VOTING
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (data.action === "vote") {
    sheet.appendRow([
      new Date(),
      data.token,
      data.org1Choice,
      data.org2Choice
    ]);
    return ContentService.createTextOutput(JSON.stringify({"result": "success"})).setMimeType(ContentService.MimeType.JSON);
  }
}

4. Klik Terapkan (Deploy) > Penerapan Baru (New Deployment) > Pilih Jenis: Aplikasi Web (Web App) > Akses: Siapa Saja (Anyone).
